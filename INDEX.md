## 🚀 Quick Start Commands

### Using Docker (Recommended)
```bash
docker-compose up -d
```

### Using npm
```bash
cd backend && npm install && npm run dev
cd frontend && npm install && npm run dev
```

### Using Setup Scripts
```bash
Windows:  setup.bat
Mac/Linux: bash setup.sh
```
